# Walk-forward results, identity dry run, clean-price backtest (2026-11-25)

## 1. Shots-on-target xG proxy: full Engine walk-forward → **ADOPTED (model 1.1.0)**
* **Setup:**
  * production `Engine` (Dixon-Coles + Elo ensemble), production parameters, same code path as `fil backtest`
    (`run_backtest(params=…, per_match=…)`);
  * holdout 2025-08-01 → 2026-11-25; the 11 backtest leagues; refit every 14 days, using only data before each
    step date;
  * paired comparison on the same matches; bootstrap clustered by week (4,000 resamples).
* **Proxy rules:**
  * real xG always comes first;
  * where it is missing and both teams' shots on target are known, xG ≈ 0.3184 × SOT;
  * the coefficient is **frozen**: goals per shot on target over 14,370 matches before 2025-07-01, i.e. before the
    holdout;
  * missing SOT stays missing, never 0.

| Comparison (n = 4,956, paired) | ΔLL [95 % CI] |
|---|---|
| **1.1.0 (SOT proxy) vs 1.0.0** | **−0.00161 [−0.00312, −0.00019]**: the CI is entirely below 0, so the merge criterion is met |
| first part, before 2026-04 (n = 2,979) | −0.00119 [−0.00301, +0.00065] |
| second part, 2026-04 onwards (n = 1,977) | −0.00223 [−0.00471, −0.00009] |

The gain is small: it closes about 9 % of the gap to the market. It is not a betting edge.

## 3. UEFA team identity: reversible alias map, dry run only → `docs/data/UEFA_IDENTITY_DRYRUN.md`
* `python -m fil identity-dry-run OUT.md --json OUT.json` opens the database **read-only** and only writes the
  report.
* **Result:**
  * 137 "Europe" teams;
  * **56 proposed merges** (exact names, a short curated list and one near-identical spelling), re-pointing
    1,115 fixture columns;
  * 0 ambiguous;
  * 81 unmatched: clubs from countries we don't cover, which stay as they are.
* **Problems the dry run surfaces (must be resolved before any apply):**
  * Atleti would play twice on 21 and 28 Jan. These are Athletic Club games wrongly aliased as Atleti; the alias
    must be removed first.
  * The Como–AEK duplicate fixture: two Europe ids map onto one domestic Como.
  * "Andorra" and "Monaco" ids are shared by club and national-team fixtures.
* **Design:** apply and revert go through a `team_merges` journal that records every re-pointed fixture column,
  so the merge can be undone exactly. Immutable tables reference fixtures, not teams, so no audit record is
  touched.
* **Not applied.** It needs three things first:
  1. A person reviews the curated and fuzzy rows.
  2. A domestic walk-forward re-backtest with merged ids shows no regression. Cup results will then feed domestic
     Elo.
  3. A UEFA prediction path exists: Engine A fits Dixon-Coles only for domestic leagues.

## Disagreements and rulings
The skeptic changed the fallback design:
- **Names:** `names_match` accepts equal names, or the shorter name's words as the start or end of the longer ("bradford" ⊂ "bradford city", "verona" ⊂ "hellas verona"). A small expansion map used **only** by the fallback adds "weds→wednesday" and "rvs→rovers". `teamnames.normalize` is unchanged, because stored `alias_norm` rows depend on it.
- **Uniqueness, both directions:** one fixture per event and one event per fixture, otherwise the match is dropped.
- **Order:**
  1. a per-fixture search for open-bet fixtures,
  2. the day lists,
  3. per-fixture searches for the rest.
- **Budget and cache:** 8 network requests per run; fresh cached answers don't count. A day list is cached 12 h only once every match of that day is surely over (otherwise 2 h).
- **Daily job:** also runs the step.
- **UI:**
  - `statusNow` / `awaitingResult` are rebuilt on `matchState`, which fixes TodayCard, Predictions and InsightDetail in one place; Insights and Compare use the same rule.
  - Legacy bankroll values are tagged **"legacy (€100 bankroll)"** with the raw values in a tooltip, not hidden (audit trail).
  - Legacy rows are picked by date, not by amount.

# v2.0.0 — AI Match Insights (Engine B) + live-data foundation

## Highlights
- **Engine B — AI Match Insights.** An independent statistical engine (`eb-insights 1.0.0`) with its own features,
  Poisson GLMs for goals, corners, cards, shots, shots on target and fouls, a Dixon-Coles correction, negative-binomial
  totals, immutable prediction records with feature snapshots, and its own validation.
- **Markets.** 1X2, double chance, BTTS, Over/Under 0.5–4.5, the full correct-score matrix, clean sheets, first team to
  score, expected goals, corners (Over 7.5–10.5 plus team lines), yellow cards (Over 2.5–4.5 plus team lines), the league
  red-card rate, and expected shots, shots on target and fouls. Markets without reliable data are shown as unavailable.
- **AI Match Analyst.** Evidence-only reports: assessment, goals, corners, cards, form, head to head, league table,
  supporting factors, contradicting factors, missing information, and Engine A vs Engine B vs market.
- **Engine B virtual bankroll.** A separate €100 with medium-risk rules. 1X2 selections are disabled because validation
  showed a significant loss (ROI −23.5%, 95% CI −36.7%…−9.8%, 470 bets).
- **Live mode.** A provider-agnostic live layer with timestamped snapshots and events, in-play probabilities,
  LIVE/DELAYED/STALE labels, and a polling job every 20 minutes. football-data.org delayed scores are active; the
  API-Football adapter is ready and needs `API_FOOTBALL_KEY`.
- **Global coverage.** 63 competitions classified FULL / PARTIAL / FIXTURES AND RESULTS ONLY / LIVE SCORES ONLY /
  COVERAGE ONLY / UNAVAILABLE.
- **Dashboard.** A new "AI MATCH INSIGHTS" section: Match Insights, match detail, Engine A vs B, Engine B track record,
  and Global coverage & live data.

## Validation (walk-forward, 4,845 identical matches)
- **1X2 log loss:** Engine A 0.9949, Engine B 1.0000, market 0.9819, naive 1.0768.
- **Over/Under 2.5:** Engine B 0.6805, better than Engine A's 0.6858. **BTTS:** Engine B 0.6861, better than Engine A's 0.6871.
- **Corners:** no skill over the league mean (labelled on every report). **Cards:** a small gain.

## Unchanged
Engine A: no code changes, a golden regression test, and its own ledger untouched.
